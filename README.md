# Evaluacion-2 (Unity)

Proyecto Unity con estructura de assets organizada y configuración base de Git.

## Requisitos

- Unity Hub + versión de Unity definida en `ProjectSettings/ProjectVersion.txt`.

## Clonar el proyecto

```bash
git clone <URL_DEL_REPO>
cd Evaluacion-2
```

## Abrir en Unity

1. Abrir Unity Hub.
2. Click en "Add" y seleccionar la carpeta del proyecto.
3. Abrir el proyecto con la versión indicada.

## Estructura de Assets

La guía completa está en `Docs/ASSETS_STRUCTURE.md`.

## Notas

- `Library/` y otros archivos generados están ignorados por Git.
- Los paquetes de terceros se mantienen en sus carpetas originales.
